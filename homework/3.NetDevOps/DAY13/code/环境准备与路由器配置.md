## 9. 如果验证失败，优先检查这些点

如果你执行`show`命令后结果不符合预期，优先检查：

1. 两台路由器的`GigabitEthernet2`是否真的互通
2. 两端`172.16.12.1/24`与`172.16.12.2/24`是否正确生效
3. BGP邻居IP是否使用互联口地址而不是管理口地址
4. `address-family ipv4`下是否已经看到`neighbor x.x.x.x activate`
5. Loopback网段是否确实存在于本机路由表中，BGP `network` 通告要求本地必须有对应路由
