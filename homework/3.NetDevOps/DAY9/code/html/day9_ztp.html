QYTang ZTP 服务器

欢迎使用零接触部署（ZTP）服务器。

使用说明

设备可以通过以下URL获取配置：

/ztp/<device_type>/<device_sn>/<interfaces>

例如：

http://<server>/ztp/C8000V/96WA1AWBIHB/GigabitEthernet1,GigabitEthernet2,GigabitEthernet3

配置数据分离架构

  • 设备类型通用配置：相同类型设备的通用配置（C8000V.template + C8000V.yaml）
  • 设备特殊配置：每个设备独有的配置（序列号.yaml + 接口/OSP模板）
