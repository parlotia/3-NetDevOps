任务一: 配置BGP邻居与maximum-prefix阈值
================================================================================

目的: 使R1在接收R2发布的前缀达到阈值时产生%BGP-4-MAXPFX SYSLOG日志

1.1 配置R1 Loopback0和R2 Loopback0/1 (为BGP network命令提供路由)
    R1: interface Loopback0, ip address 1.1.1.1 255.255.255.0
    R2: interface Loopback0, ip address 2.2.2.2 255.255.255.0
    R2: interface Loopback1, ip address 22.2.2.2 255.255.255.0

1.2 配置R1 BGP AS 65001:
    router bgp 65001
     bgp log-neighbor-changes
     network 1.1.1.0 mask 255.255.255.0
     neighbor 10.10.1.201 remote-as 65002
     neighbor 10.10.1.201 ebgp-multihop 255
     neighbor 10.10.1.201 maximum-prefix 2 warning-only

1.3 配置R2 BGP AS 65002:
    router bgp 65002
     bgp log-neighbor-changes
     network 2.2.2.0 mask 255.255.255.0
     network 22.2.2.0 mask 255.255.255.0
     neighbor 10.10.1.200 remote-as 65001
     neighbor 10.10.1.200 ebgp-multihop 255

1.4 验证:
    show ip bgp summary                          ! 查看BGP邻居状态和前缀数
    show logging | include MAXPFX                ! 查看maximum-prefix告警日志

1.5 触发后的SYSLOG日志格式:
    %BGP-4-MAXPFX: Number of prefixes received from 10.10.1.201 (afi 0) reaches 2, max 2

自动化脚本: task1_bgp_max_prefix.py (RESTCONF自动配置, 含CLI备用命令)

================================================================================
任务二: 配置EEM Applet + Guestshell脚本部署
================================================================================

目的: EEM捕获BGP告警日志, 自动调用Guestshell脚本发送邮件

2.1 启用IOx和Guestshell:
    configure terminal
     iox
    end
    ! 等待1-5分钟IOx初始化
    guestshell enable

2.2 配置Guestshell网络 (关键! 必须配guest-ipaddress):
    configure terminal
     interface VirtualPortGroup0
      ip address 192.168.1.1 255.255.255.0
      ip nat inside
     interface GigabitEthernet2
      ip nat outside
     ip nat inside source list 1 interface GigabitEthernet2 overload
     access-list 1 permit 192.168.1.0 0.0.0.255
     app-hosting appid guestshell
      app-vnic gateway0 virtualportgroup 0 guest-interface 0
       guest-ipaddress 192.168.1.2 netmask 255.255.255.0
      app-default-gateway 192.168.1.1 guest-interface 0
      name-server0 8.8.8.8
    end

    ! 注意: guest-ipaddress 必须在 app-vnic gateway0 子模式下配置!
    ! 注意: NAT outside必须配在实际上网口(本实验是Gi2, 不是Gi1)!

2.3 重启Guestshell使网络配置生效:
    guestshell disable
    guestshell enable

2.4 部署脚本到Guestshell:
    configure terminal
     file prompt quiet
    end
    copy ftp://admin:Cisc0123@10.10.1.110/bgp_threshold_notification.py bootflash:
    copy ftp://admin:Cisc0123@10.10.1.110/qyt_smtp_attachment.py bootflash:
    copy bootflash:bgp_threshold_notification.py bootflash:guest-share/
    copy bootflash:qyt_smtp_attachment.py bootflash:guest-share/
    guestshell run bash -c "cp /bootflash/guest-share/bgp_threshold_notification.py /home/guestshell/"
    guestshell run bash -c "cp /bootflash/guest-share/qyt_smtp_attachment.py /home/guestshell/"

2.5 配置EEM Applet:
    configure terminal
     event manager applet bgp_prefix_threshold_notification
      event syslog pattern "BGP-4-MAXPFX"
      action 1.0 regexp "from ([0-9.]+)" "$_syslog_msg" ipaddr
      action 2.0 regexp "reaches ([0-9]+)" "$_syslog_msg" current_prefix
      action 3.0 regexp "max ([0-9]+)" "$_syslog_msg" max_prefix
      action 4.0 string trim "$ipaddr"
      action 5.0 string trim "$current_prefix"
      action 6.0 string trim "$max_prefix"
      action 7.0 cli command "guestshell run python3 /home/guestshell/bgp_threshold_notification.py received from $ipaddr : $current_prefix exceeds limit $max_prefix"
    end

自动化脚本: task2_eem_guestshell.py

================================================================================
踩坑记录 (重要!)
================================================================================

1. guest-ipaddress必须在gateway0子模式下配置
   错误: 在app-hosting appid guestshell下直接输入guest-ipaddress → Invalid input
   正确: 先输入app-vnic gateway0 virtualportgroup 0 guest-interface 0进入子模式, 再输入guest-ipaddress
   这是Guestshell eth0获取IP的必要配置, 缺少则eth0无IP, 网络完全不通

2. NAT outside必须配在实际上网口
   本实验Gi1(10.10.1.200)是管理口, Gi2(192.168.72.132/DHCP)才是上网口
   必须确认哪个接口能访问互联网

3. Guestshell中bash -c不支持&&复合命令
   错误: guestshell run bash -c "cp x y && chmod +x y"
   正确: 分两步执行: guestshell run bash -c "cp x y" 然后 guestshell run bash -c "chmod +x y"

4. Guestshell Python 3.6不支持sys.stdout.reconfigure()
   错误: sys.stdout.reconfigure(encoding='utf-8')
   正确: sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding='utf-8')

5. Guestshell中/etc/resolv.conf不可写(Permission denied)
   解决: 通过app-hosting的name-server0 8.8.8.8配置DNS, 不需要手动写resolv.conf

6. SCP/SFTP到C8KV不支持
   解决: 使用FTP中转(用户自建FTP服务器10.10.1.110)
   流程: FTP→bootflash→guest-share→Guestshell /home/guestshell/

7. bootflash文件在Guestshell中不可直接访问
   解决: 通过guest-share共享目录中转:
   copy bootflash:x bootflash:guest-share/x  (IOS-XE侧)
   cp /bootflash/guest-share/x /home/guestshell/  (Guestshell侧)

================================================================================
完整数据流
================================================================================

BGP前缀超限
  → IOS-XE产生 %BGP-4-MAXPFX SYSLOG日志
  → EEM Applet bgp_prefix_threshold_notification 捕获日志
  → EEM regexp提取: ipaddr / current_prefix / max_prefix
  → EEM执行: guestshell run python3 /home/guestshell/bgp_threshold_notification.py ...
  → Python脚本解析参数, 拼接邮件正文
  → smtplib.SMTP_SSL('smtp.qq.com', 465) 发送邮件
  → QQ邮箱收到BGP前缀阈值告警邮件

网络路径:
  Guestshell(192.168.1.2) → eth0 → VPG0(192.168.1.1) → NAT → Gi2(192.168.72.132) → 互联网 → smtp.qq.com:465
